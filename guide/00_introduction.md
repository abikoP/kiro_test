## 🏗️ 作成するシステムの概要

### Telegraf設定ファイル管理システムとは

Telegrafは、サーバーやアプリケーションのメトリクスを収集するツールです。このシステムは、TelegrafがHTTP監視するURLの一覧を、Webブラウザから簡単に管理できるようにするものです。

### 主な機能

1. **公開ページ** (`/conf`)
   - 誰でもアクセス可能
   - 現在監視中のURL一覧を表示

2. **ログイン機能** (`/auth/login`)
   - ユーザ名とパスワードで認証
   - セッション管理

3. **管理画面** (`/admin`)
   - 認証済みユーザーのみアクセス可能
   - ダッシュボード表示

4. **URL一覧表示** (`/admin/list`)
   - 登録済みURLをテーブル形式で表示

5. **URL編集機能** (`/admin/edit`)
   - URLの追加・削除
   - 複数URLの一括操作
   - 入力バリデーション

### 技術スタック

- **言語**: Rust (Edition 2021)
- **Webフレームワーク**: Loco 0.13
- **ORM**: SeaORM
- **データベース**: SQLite
- **認証**: bcrypt + tower-sessions
- **設定ファイル**: TOML

## 🚀 学習の進め方

### 推奨する学習方法

1. **順番に読む**
   - 第0章から順番に進めてください
   - 各章は前の章の知識を前提としています

2. **実際にコードを書く**
   - 読むだけでなく、必ず自分の手でコードを書いてください
   - タイピングすることで、記憶に定着します

3. **動かして確認する**
   - コードを書いたら、必ず実行して動作を確認してください
   - `cargo run`や`cargo test`を積極的に使いましょう

4. **エラーを恐れない**
   - エラーは学習の機会です
   - エラーメッセージをよく読んで、何が問題なのか理解しましょう

5. **理解できない部分は飛ばさない**
   - わからない部分があったら、補足資料を読むか、前の章に戻って復習しましょう
   - 理解が曖昧なまま進むと、後で困ります

6. **完成したコードと比較する**
   - 各章の最後に、完成したコードが載っています
   - 自分のコードと比較して、違いを確認しましょう

### 学習時間の目安

- **第0章**: 1〜2時間（Rust経験者は30分）
- **第1章〜第10章**: 各章2〜4時間
- **合計**: 20〜40時間程度

自分のペースで進めてください。理解を優先し、焦らないことが大切です。
